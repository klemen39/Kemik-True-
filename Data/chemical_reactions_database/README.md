# Chemical Reactions Database

This package contains 220 balanced chemical reactions in English and Slovene.

Files:
- all_reactions.json: combined database
- reaction_metadata.json: schema and category counts
- one JSON file per reaction category

Important:
- Some equations are ionic rather than molecular.
- Conditions, ionic equations, oxidation numbers, energy classification, gas and precipitate fields are intentionally left null/unknown where they were not encoded with high confidence.
- A few equations are simplified educational representations, as stated in their notes.
